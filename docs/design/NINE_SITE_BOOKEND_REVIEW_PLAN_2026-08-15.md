# Nine-site visual bookend review plan

Status: working review plan; no screen is approved until Chinmay reviews it in
the current project pass.

WikiWhy is excluded. Its complete state sequence remains in the source task.

## Deliverable contract

For each remaining site, author the fixed 1440 x 900 shell in this order:

1. exact Phase 1 corrupted base;
2. exact Phase 1 repaired base, reusing the same geometry;
3. after those bookends are reviewed, one Act 2 super-corrupted base;
4. later, passage deltas and the separate Act 2 checklist overlay.

Dialogue popups, Techno overlays, passage-by-passage transitions, and Act 2
repair animation are deliberately excluded from this pass.
