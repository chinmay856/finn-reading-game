## Approved concept qualities

- Each site looks and behaves like its own transformed Internet archetype.
- Each site has a readable corrupted state, a rule-changing midpoint, and a
  satisfying secured state.
- Each site uses a mechanic native to its subject rather than a generic repair
  meter.
- The Reading Companion remains distinct from decorative site content.
- Humor, evidence, and visible consequence support the reading loop.

## Known refinement requirements

- Replace inconsistent character depictions with reviewed Amy, Chinmay, and
  Techno states. MyCorner, Yahuh, WikiWhy, and other boards contain older
  character treatments; some depict Chinmay with short hair.
- Re-author all popup, cutscene, button, and essential site copy. Generated
  board text is illustrative unless separately approved.
- Normalize the shared outer-game visual grammar without flattening each site's
  native identity.
- Define one fixed-aspect player composition and a layer plan for corrupted,
  midpoint, progress, and secured states.
- Separate decorative image content from semantic/accessibility text and the
  genuinely interactive Reading Companion.
- Validate every narrative with multiple clearly labeled simulated teen and parent
  perspectives before asking Chinmay to approve it, followed by real-player
  validation when practical.
- Review all names, claims, dates, links, products, prices, maps, posts, songs,
  citations, and source references for story intent, accuracy, and rights.
