# Character candidate review card — for Chinmay preview

Status: **concept direction accepted by Chinmay; not frozen for build**

The three sheets below are the strongest coherent character candidates found in
the repository. On 2026-08-14, Chinmay accepted them as good working directions
for the current refinement phase. Their old filenames and state names remain
identification aids rather than proof of build approval. Material changes,
animation, runtime crops, and newly drawn poses remain reviewable.

## Cross-character checks

- Do all three characters look as though they belong in the same illustrated
  game, with compatible line weight, shading, warmth, and level of detail?
- Should site scenes use direct crops from these sheets or newly drawn poses that
  obey a locked model sheet?
- How large may each character appear relative to the Reading Companion?
- Which character, if any, can move while highlighted reading is active?
- Are Amy's authority, Chinmay's comic escalation, and Techno's visual curiosity
  distinct without any character explaining the lesson for the player?
